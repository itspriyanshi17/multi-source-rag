# Return Policy

NovaTech Electronics offers a **30-day return window** on most products, starting from the date
of delivery. To be eligible for a return, items must be in their original condition with all
included accessories, manuals, and packaging.

## General Rules
- Refunds are issued to the original payment method within 5-7 business days of the returned
  item passing inspection.
- Return shipping is free for defective or incorrectly shipped items; otherwise a $6.99 return
  shipping fee applies.
- Items marked "Final Sale" at time of purchase are not eligible for return.

## Category Exceptions
- **Accessories** (chargers, cables, mice, keyboards): 15-day return window due to hygiene and
  resale considerations.
- **Opened laptops**: see the individual product manual, as some laptop lines have a shorter
  return window once the device has been powered on and registered.
- **Gaming consoles**: must be returned within 20 days and cannot show signs of use beyond basic
  setup.

## How to Start a Return
1. Log into your NovaTech account and go to Order History.
2. Select the item and choose "Start a Return."
3. Print the provided shipping label and drop the package off at any authorized carrier location.

Questions about a specific return should reference your order number when contacting support.
