# Support Ticket #10560 — Monitor Warranty Claim

**Customer:** My NovaView 27 QHD monitor has 2 dead pixels in the bottom corner. Can I get it
replaced under warranty?

**Agent:** Thanks for reaching out. Our warranty policy covers dead/stuck pixel replacement only
when there are more than 3 dead or stuck pixels within the first 90 days — 2 pixels is within
normal manufacturing tolerance, so this particular case wouldn't qualify for a free replacement
under the standard policy.

**Customer:** That's disappointing, is there anything you can do?

**Agent:** I can offer a 15% discount code toward a replacement or a different monitor model as
a goodwill gesture, since I understand even a couple of dead pixels can be distracting.

**Customer:** I'll take the discount code for now and monitor if more pixels appear.

**Resolution:** Goodwill 15% discount code issued; case does not meet warranty replacement
threshold. Ticket closed, customer advised to reopen if pixel count increases within 90 days.
